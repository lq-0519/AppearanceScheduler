# 外观定时器

macOS 菜单栏工具。设置每天切到浅色和深色的时间，也可以从菜单立即切换系统外观。

## 使用

1. 打开应用，点击菜单栏的半黑半白圆形图标。
2. 在「设置…」里选择两个不同的时间并保存。保存后会立即应用当前时段的外观。
3. 首次切换时，允许「外观定时器」控制「系统事件」。如果已经拒绝，可在「系统设置 → 隐私与安全性 → 自动化」里授权。
4. 要在下次登录后自动运行，在菜单里勾选「登录时启动」。

从菜单手动切换会持续到下一个计划点。Mac 从睡眠唤醒后，应用会根据当前时间补切。时间表跟随系统时区，每次只安排下一次切换，平时无需轮询。

## 构建

需要 macOS 13 或以上及 Apple 命令行开发工具。脚本给当前处理器构建 `.app`，输出路径使用绝对路径。

```sh
./build.sh /tmp/AppearanceScheduler.app
```

脚本默认使用临时签名。需要在后续重装时沿用应用身份，可通过 `SIGNING_IDENTITY` 指定本机的代码签名证书。将构建好的应用移入「应用程序」即可使用。
